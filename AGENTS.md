# Repository Agent Instructions

## Required task summaries

For every user question, investigation, review, or code/configuration fix completed in this repository:

1. Write or append the detailed final response to the root `summary.md` file.
2. Preserve all existing content in `summary.md`; do not overwrite or remove earlier entries.
3. Add a clear dated heading for each new entry so that responses remain easy to distinguish.
4. Never write credentials, API keys, access tokens, signing secrets, passwords, or other sensitive values to `summary.md`. Refer to the environment-variable name and secure file location instead.
5. In chat, provide only a brief completion confirmation and a link to `summary.md`. Do not repeat the detailed summary in chat unless the user explicitly requests it there.
6. These instructions do not replace required error messages, approval requests, blocking questions, safety warnings, or other information that must be communicated directly to the user.
